## Структура программы

В проекте используются следующие классы:

- `Time` — хранение времени в секундах с начала суток;
- `Home` — количество этажей дома;
- `Gun` — количество патронов и логика демонстрации выстрела;
- `Department` — название отдела, начальник и список сотрудников;
- `Employee` — имя сотрудника и ссылка на отдел.

Основная логика работы программы находится в файлах:

- `Lab_3/main.cpp` — главное меню и интерфейс пользователя;
- `Lab_3/header.h` — объявления классов;
- `Lab_3/header.cpp` — реализации методов классов.

## Задание 1

### Класс `Time`

#### Описание задачи

Реализовать класс `Time`, который хранит время в 24-часовом формате в виде количества секунд, прошедших с начала суток. Класс должен обеспечивать корректное изменение значения времени и его вывод в читаемом виде.

#### Основные методы

- конструктор с инициализацией значением в секундах;
- метод `setSeconds(int seconds)` для изменения времени;
- метод `print()` для вывода в формате `чч:мм:сс`;
- корректная проверка входных данных.

#### Алгоритм решения

1. Ввести значение секунд с проверкой, чтобы оно было неотрицательным.
2. Сохранить значение в закрытом поле класса `seconds`.
3. Для вывода перевести секунды в часы, минуты и секунды.
4. Реализовать методы изменения значения и повторного вывода.
5. Добавить пользовательское меню для выбора действий.

## Задание 4

### Классы `Department` и `Employee`

#### Описание задачи

Реализовать систему, в которой есть отделы и сотрудники. У каждого отдела есть название, начальник и список сотрудников. У сотрудника есть имя и информация о том, к какому отделу он относится.

#### Основные требования

- создание отдела;
- создание сотрудника и привязка к отделу;
- назначение начальника отдела;
- вывод информации об отделе и сотруднике;
- возможность получить всех сотрудников определённого отдела.

#### Дополнительная задача 3.4

Для выбранного сотрудника необходимо вывести список всех сотрудников его отдела.

#### Алгоритм решения

1. Создать класс `Department`, содержащий название отдела, указатель на начальника и вектор сотрудников.
2. Создать класс `Employee`, содержащий имя сотрудника и указатель на отдел.
3. Реализовать методы добавления сотрудника, назначения руководителя и вывода данных.
4. Для каждого отдела хранить список сотрудников и получать их по запросу.
5. В главном меню добавить команды для создания отделов, сотрудников, назначения руководителя и вывода данных.
